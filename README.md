# SCHOOLHOUSE SURVIVAL

A complete, working Roblox game inspired by **Baldi's Basics**, built from the 8-phase plan:
collect all 10 notebooks scattered around a school, manage your stamina, buy items with
Nickels, dodge three very different AI characters, and escape through the EXIT door.

Everything — the school map, the UI, the NPC rigs, the item models — is **generated by code
at runtime**, so the game runs in any empty Baseplate place with zero manual Studio work.

---

## How to install (pick one)

### Option A — one-paste installer (no tools needed)

1. Open **Roblox Studio** → new **Baseplate** place (any place works).
2. Open the command bar: **View → Command Bar**.
3. Open [`installer/InstallBaldiGame.lua`](installer/InstallBaldiGame.lua), copy the
   **entire file**, paste it into the command bar, press **Enter**.
4. You'll see `[BaldiGame] Installed 25 scripts.` — press **Play** (F5).

Re-running the installer cleanly replaces a previous install.
(Regenerate it after editing `src/` with `python3 tools/build_installer.py`.)

### Option B — Rojo (for development)

1. Install [Rojo](https://rojo.space) (CLI + Studio plugin).
2. `rojo serve` in the repo root, then **Connect** from the Studio plugin.
3. Press **Play**.

## How to play

| Input | Action |
|---|---|
| WASD / left stick | Move |
| **Shift** (hold) / mobile **RUN** toggle | Sprint (drains stamina) |
| **E** / mobile **USE** | Use item in slot 1 — also collects notebooks / opens vending machines when prompted |
| **Q** / mobile **SWAP** | Swap item slots |
| Mouse | Look (first person during a round) |

**Goal:** press PLAY → collect all **10 notebooks** (E near a notebook) → the EXIT door at
the entrance corridor turns green → touch it to escape. Your time is tracked; beat your best.

**The cast:**

| Character | Archetype | Behaviour |
|---|---|---|
| **ChatRevive** (red) | On-sight chaser | Roams; raycast sight check every 0.3s; chases on sight (you can outrun it only by sprinting); catching you = game over, drops a Nickel where you fell. **Enrages at 10/10 notebooks.** |
| **LP** (navy) | Condition chaser | Roams; only reacts if it **sees** you moving **faster than 20** (sprint = 24, walk = 16). Once triggered it barely loses ground — get out of its sight. Caught = **15s detention**, not game over. |
| **Frosty** (ice) | Passive roamer | Wanders waypoint to waypoint, waiting 1–2s at each. Never chases. Within 6 studs you're chilled: 0.4× speed for 4s (it chills ChatRevive and LP too — use it!). |

**Items** (2 slots, slot 1 is active):

- **BSODA** — projectile that knocks any character back 20 studs and stuns it 3s. Your escape window.
- **Zesty Bar** — instantly refills stamina to 100 and clears exhaustion.
- **Nickel** — currency, not an item slot. Dropped by ChatRevive catches, a few spawn in the
  halls each round. Spend at the two vending machines in the south hall (1 Nickel each).

**Stamina:** sprint drains 10/s; regen 6/s; at 0 you're exhausted (red bar, shake) and sprint
locks until 30. The bar turns yellow under 30%.

## The Roblox structure

This is the exact instance tree after install (Rojo and the installer produce the same thing):

```
ServerScriptService
└── BaldiGame                  (Folder)
    ├── Main                   (Script)        — bootstrap, init order, ctx wiring
    ├── RemoteSetup            (ModuleScript)  — creates the RemoteEvents folder
    ├── MapBuilder             (ModuleScript)  — generates the whole school at runtime
    ├── NpcFactory             (ModuleScript)  — builds R6 rigs in code
    ├── NpcBase                (ModuleScript)  — shared pathfinding/LoS/stun/slow base
    ├── GameManager            (ModuleScript)  — round state machine, win/lose, gating
    ├── NotebookSpawner        (ModuleScript)  — tag fetch, Fisher-Yates, 10 clones, collect
    ├── ChatReviveAI           (ModuleScript)  — on-sight chaser
    ├── LpAI                   (ModuleScript)  — condition chaser (speed + LoS)
    ├── FrostyAI               (ModuleScript)  — passive roamer + proximity debuff
    ├── DetentionSystem        (ModuleScript)  — teleport, anchor, countdown, release
    ├── ItemEconomy            (ModuleScript)  — inventory, nickels, vending, BSODA
    └── ExitDoorManager        (ModuleScript)  — locked/open door, win trigger

ReplicatedStorage
├── BaldiShared                (Folder)
│   └── GameConfig             (ModuleScript)  — every tunable number, shared both sides
├── BaldiRemotes               (Folder)        — 20 RemoteEvents (created at runtime)
└── BaldiModels                (Folder)        — Notebook template (created at runtime)

StarterPlayer
└── StarterPlayerScripts
    └── BaldiClient            (Folder)
        ├── Main               (LocalScript)   — client bootstrap, controller init order
        ├── UiKit              (ModuleScript)  — UI helpers + theme (all UI is code-built)
        ├── SoundController    (ModuleScript)  — rbxasset:// sounds only, pcall-safe
        ├── InputHandler       (ModuleScript)  — Shift/E/Q + mobile button routing
        ├── HudController      (ModuleScript)  — counter, nickels, stamina bar, slots, banners
        ├── StaminaController  (ModuleScript)  — drain/regen/exhaustion/debuff, WalkSpeed
        ├── ItemUseClient      (ModuleScript)  — slot mirror, use/swap input
        ├── VendingMachineUI   (ModuleScript)  — buy popup, walk-away close
        ├── DetentionOverlay   (ModuleScript)  — countdown overlay, sprint lock
        ├── FrostyVignette     (ModuleScript)  — icy screen edges + slow application
        └── MenuController     (ModuleScript)  — main menu, countdown, win/lose screens

Workspace (generated at runtime by MapBuilder)
└── BaldiMap                   (Folder)
    ├── Geometry               — floors, walls, desks, shelves, exit door, vending machines, lobby
    ├── Waypoints              — 15 invisible AI roam nodes
    ├── NotebookSpawns         — 23 invisible nodes, tagged "NotebookSpawn"
    ├── Notebooks              — the 10 live notebooks each round
    ├── Pickups                — nickels + world items
    ├── Npcs                   — ChatRevive, LP, Frosty rigs
    └── Projectiles            — live BSODA blasts
```

The map: a hallway ring around a central block (which houses the **detention room**), four
classrooms (north/south), the **gym** (west), the **library** with tight shelf aisles (east),
an entrance corridor with the **EXIT door**, two **vending machines** in the south hall, and a
separate lobby where players wait in the menu.

> Want a hand-built map instead? Create your own `Workspace/BaldiMap` folder with the same
> child folders and MapBuilder will skip generation. Any part you tag `NotebookSpawn` in
> Studio (Tag Editor) is automatically included in the random pool.

## How the plan's 8 build phases map to the code

1. **Main menu + end screens** → `MenuController` (CanvasGroup fades, PLAY → `RequestStart`,
   win = green/time/best, lose = red/catcher/cause, Retry + Menu buttons).
2. **HUD shell** → `HudController` (notebook counter top-center, nickel count + coin icon
   top-right, objective line, center banners).
3. **Stamina bar** → `StaminaController` + the bar in `HudController`. Heartbeat tick,
   16→24 WalkSpeed, −10/s drain, +6/s regen, lockout at 0, re-enable at 30, green/yellow/red
   states with shake on exhaustion. Zesty resets it via the `StaminaRestore` remote.
4. **Item slots UI** → `ItemUseClient` + `ItemEconomy`. Two slots, E use / Q swap, walk-over
   pickup, "Inventory full" flash, server-validated `UseItem`.
5. **Random notebook spawning** → `NotebookSpawner`. `CollectionService:GetTagged`,
   Fisher-Yates shuffle, 10 of 23 nodes, ProximityPrompt collect, `NotebookCollected` → HUD.
6. **ChatRevive** → `ChatReviveAI` on the shared `NpcBase` (roam / 0.3s raycast LoS / chase
   with 0.5s re-path / last-known-position memory / catch → `PlayerLost` + Nickel drop).
7. **LP** → `LpAI` + `DetentionSystem` + `DetentionOverlay` (speed-over-20-AND-LoS condition,
   chase, teleport to detention, 15s anchored countdown, release immunity).
8. **Frosty** → `FrostyAI` + `FrostyVignette` (waypoint loop with 1–2s waits, 6-stud
   Heartbeat magnitude check, `SpeedDebuff` → 0.4× for 4s + vignette; also slows other NPCs).

Activation gating: **0 notebooks = everyone frozen → 1st notebook = everyone activates →
10th notebook = enrage + exit phase** — implemented in `GameManager.onNotebookCollected`.

### Deliberate deviations from the plan (and why)

- **"Silver enrages" at 10/10** — Silver appears in the plan only in that line; the enrage is
  wired to **ChatRevive** (the primary antagonist): +speed, faster sight checks, dark-red glow.
- **LP checks horizontal velocity, not `Humanoid.WalkSpeed`** — client-set WalkSpeed never
  replicates to the server, so the property check the plan describes is impossible *and*
  spoofable. Actual velocity replicates and can't be faked downward. Same 20 threshold,
  same outcome: sprint (24) triggers, walk (16) is safe.
- **Q swap goes through the server** — the plan calls it client-only, but inventory is
  server-authoritative (anti-cheat), so the swap is a tiny remote; it still feels instant.
- **Catches use a radius check, not `Touched`** — `Touched` is unreliable on welded rigs;
  a 4-stud Heartbeat distance check is deterministic.
- **A couple of starter Nickels + one free BSODA/Zesty spawn per round** — so a tester can
  experience the vending machines and items without dying first. Turn off via
  `GameConfig.NICKELS_AT_ROUND_START` / `WORLD_ITEMS_AT_ROUND_START`.

## Testing checklist (what "satisfied" looks like)

- [ ] Menu appears; PLAY → 3-2-1 countdown → first-person spawn in the entrance corridor.
- [ ] HUD shows 0/10 notebooks, nickels, full green stamina bar, two empty slots.
- [ ] Sprint drains the bar; at 0 it flashes red, shakes, and locks until 30; walking regens.
- [ ] Collecting notebook #1 plays a ping, bumps the counter, and **wakes all three NPCs**
      ("You hear footsteps..." banner).
- [ ] ChatRevive chases when it sees you (snap-snap sound), loses you around corners, and
      catching you shows the red CAUGHT screen + drops a Nickel.
- [ ] Walking past LP is safe; **sprinting in his sight** gets you dragged to detention with
      a 15s countdown overlay, then released.
- [ ] Frosty never chases, but brushing him shows the icy vignette and slows you.
- [ ] Nickels ding on pickup; vending machine prompt opens the popup; buying with 0 Nickels
      fails politely; with 1 Nickel the item lands in a slot.
- [ ] BSODA knocks ChatRevive back 20 studs and stuns it (white flash) — your escape window.
- [ ] Zesty instantly refills stamina mid-exhaustion.
- [ ] At 10/10: "GET TO THE EXIT!" banner, door turns green, ChatRevive goes dark and fast.
- [ ] Touching the green door shows ESCAPED! with your time and session best; Retry restarts.

## Tuning

Open `ReplicatedStorage/BaldiShared/GameConfig` — every speed, rate, threshold, timer, cost
and count lives there, on both server and client. Make ChatRevive faster than a sprinter
(`CHASE_SPEED = 25`) if you want real terror.
